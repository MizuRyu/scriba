# 01 Overview

## ツール名

**Scriba**

## 目的

オンライン会議（Teams など）の音声をローカルで録音し、逐次的に文字起こしする個人用CLIツール。
会議中にワンアクションで録音ON/OFFでき、終了後に文字起こし済みテキストが手元に残る。

## ユーザー

会議を手元で記録したい個人。日本語の会議を主に想定する

## 前提環境

- macOS 14.2 以降 / Apple Silicon
- BlackHole 2ch + 複数出力装置（音声キャプチャ）
- 外部マイク + ヘッドフォン（2トラック録音の前提。スピーカー運用だとマイクに相手の声が混入）
- switchaudio-osx（出力デバイスの自動切替）
- mlx-whisper + large-v3-turbo（文字起こしエンジン）
- Raycast（ショートカット起動）

## 実証済みの技術スタック

| 要素 | 技術 | 実測値 |
|---|---|---|
| 音声キャプチャ | BlackHole 2ch → sounddevice (PortAudio/CoreAudio) | 欠落ゼロ（トーンテストで実証） |
| 文字起こし | mlx-whisper (Metal GPU) | 120秒音声を6秒で処理（20x） |
| チャンク方式 | sounddeviceのサンプル数ベースで分割 | チャンク長ぴったりに確定 |

※ ffmpeg (avfoundation) キャプチャは周期的なサンプル落ち（実測約10%、約107ms/秒。
BlackHole・物理マイク双方で発生）のため2026-07-02に不採用とした。
ffmpegはmlx-whisperの音声読み込み用に引き続き必要。

## スコープ

### やること

- 録音のON/OFF制御（CLI + Raycast）
- 録音ON時のオーディオ設定バリデーション + 出力デバイス自動切替（switchaudio-osx）
- 2トラック録音（BlackHole=相手 / マイク=自分）→ `[自分]`/`[相手]` ラベル付き文字起こし
- チャンク録音 → 逐次文字起こし
- 辞書機能（initial-prompt用語 + 置換辞書。固有名詞の誤変換対策）
- 文字起こし結果のHTMLビューア（白黒シンプル）
- 設定ファイルによるカスタマイズ（保存先、ファイル名、保持期間等）
- 処理パフォーマンスのログ記録（JSONL）と可視化
- 録音ファイルの自動削除（N日後）

### 将来検討（今回スコープ外）

- 話者分離（pyannote — HuggingFace利用規約の制約あり。「自分 vs 相手」は2トラック録音で解決するため、相手側の複数話者分離が必要になったら再検討）
- 要約生成（LLMによる議事録自動作成）

## 設計方針

- CLIツール + Raycastから呼ぶ構成。常駐は自動録音（watch）を有効にしたときだけ
- モデルロード時間を気にする → TBD（事前ロード方式の検討が必要）
- 重い処理は避ける → 既存のmlx-whisperをuvx経由で呼ぶ軽量構成を維持
- 設定はYAML or TOMLファイル
