# 04 Workflow

## ワークフロー: liveモード（デフォルト）

```
会議開始
  │
  ▼
[1] Raycast ショートカット or `scriba start`
  │  ├─ オーディオ設定バリデーション（出力/入力デバイス、詳細は03 F1）
  │  ├─ 出力を複数出力装置に自動切替（元の出力を記憶）
  │  ├─ セッションディレクトリ作成
  │  ├─ 録音プロセス開始（system/mic 2トラック、バックグラウンド）
  │  └─ 文字起こしワーカー開始（バックグラウンド）
  │
  ▼
[2] 録音中（自動処理）
  │  ├─ 録音プロセス: 2分ごとにチャンクWAV生成（system_*/mic_*）
  │  ├─ ワーカー: 完成チャンクを検出 → mlx-whisper実行（辞書のinitial-prompt付き）
  │  ├─ ワーカー: 両トラックをタイムスタンプでマージ + 置換辞書適用 → combined.txt更新
  │  └─ ワーカー: performance.jsonlにログ追記
  │
  ▼
[3] 会議終了 → Raycast ショートカット or `scriba stop`
  │  ├─ 録音プロセス停止
  │  ├─ 出力デバイスを元に復元
  │  ├─ 最後のチャンクを文字起こし
  │  ├─ combined.txt 最終更新
  │  └─ macOS通知「文字起こし完了」
  │
  ▼
[4] 結果確認
     └─ `scriba view` or HTMLを直接開く
```

## ワークフロー: record-onlyモード

```
会議開始
  │
  ▼
[1] `scriba start --mode record-only`
  │  ├─ セッションディレクトリ作成
  │  └─ 録音プロセス開始（バックグラウンド）のみ
  │
  ▼
[2] 録音中
  │  └─ 録音プロセス: 2分ごとにチャンクWAV生成（文字起こしは走らない）
  │
  ▼
[3] 会議終了 → `scriba stop`
  │  ├─ 録音プロセス停止
  │  ├─ transcribe_on_stop=true なら自動でバッチ文字起こし開始
  │  └─ macOS通知「録音停止（文字起こし処理中...）」
  │
  ▼
[4] バッチ文字起こし（自動 or 手動）
  │  ├─ 自動: stop時に全チャンクを一括処理
  │  └─ 手動: `scriba transcribe {session}`
  │
  ▼
[5] 結果確認
     └─ `scriba view` or HTMLを直接開く
```

## ワークフロー: 常時録音

会議の録音（live / record-only）とは独立に動き、同時に使える。仕様は 03 の F13。

```
[1] `scriba listen on`（Raycast は toggle-scriba-listen.sh）
  │  └─ 常駐プロセスを起動し、PID を listen.json に書く
  │
  ▼
[2] 常駐中（自動処理。約3秒ごとに繰り返す）
  │  ├─ 既定の入力を確かめる。変わったか、音声が約10秒届かなければ開き直す（新しいセッションになる）
  │  ├─ 休止が有効なら、時間帯の中で入力も発話も無い間は入力を閉じ、入力があるか時間帯が終わると開き直す
  │  ├─ 電池の休止が有効なら、電池で動いている間は入力を閉じ、電源アダプタにつながると開き直す
  │  ├─ 録音: 2分ごとにチャンクWAV生成（mic_*）。時計の時が変わると、次のチャンクから新しいセッション
  │  ├─ セッションが替わったら、retention_days を超えた WAV を回収
  │  ├─ 完成チャンクを発話検出 → 発話なしなら WAV を削除
  │  │                        → 発話ありなら文字起こし + yymmdd_hhmm.txt を更新
  │  │     （listen_yield_apps のアプリがマイクを使っている間は、始めずに待つ）
  │  └─ 録音を終えたセッションに発話が 1 つも無ければ、セッションごと削除
  │
  ▼
[3] `scriba listen off`、再起動、ログアウト
     └─ 文字起こし中のチャンクを終えてから止まる。未処理のチャンクは次の起動で処理する
```

## Raycast Script Command

```bash
#!/bin/bash
# Required parameters:
# @raycast.schemaVersion 1
# @raycast.title Toggle Meeting Transcription
# @raycast.mode silent

# トグル動作
if scriba status --quiet; then
  scriba stop
  echo "録音停止"
else
  scriba start
  echo "録音開始"
fi
```

## エラーケース

| ケース | 動作 |
|---|---|
| BlackHoleが認識されない | エラーメッセージ + 利用可能なデバイス一覧を表示 |
| 入力デバイスがBlackHole | エラーで起動中止（会議アプリに自分の声が届かない状態） |
| 複数出力装置にBlackHoleが未登録 | エラーメッセージ + Audio MIDI設定の手順を案内 |
| マイクデバイスが見つからない | 警告してsystemトラックのみで録音続行（自分の声なし） |
| 録音中にstart | 「既に録音中です」と通知。二重起動しない |
| 録音プロセスのクラッシュ | ワーカーが検出して通知。PIDファイル削除 + 出力デバイス復元 |
| ディスク容量不足 | TBD |
| mlx-whisper失敗 | 該当チャンクをスキップしてログに記録。次のチャンクは継続 |
| 辞書のinitial-promptが224トークン超 | 保存時にブロック（F7のバリデーション） |
| 常時録音: 入力デバイスを開けない | 1 回通知し、開けるまで約3秒ごとに試す |
| 常時録音: 文字起こし失敗 | 該当チャンクの WAV を残してログに記録。次のチャンクは継続し、失敗したチャンクは次の起動で再試行 |
| 常時録音: 常駐プロセスのクラッシュ | 通知しない。`scriba status` に「常時録音: 動作中」が出なくなる。`scriba listen on` で起動し直すと、未処理のチャンクから処理する |

## 日次メンテナンス

```
毎日 or start時
  │
  ▼
retention_days を超えたセッションの chunks/ を削除
  │
  ▼
削除ログを出力
```
