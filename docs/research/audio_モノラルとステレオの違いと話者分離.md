# モノラルとステレオの違い、なぜステレオで話者分離できるのか

## そもそも音声データとは

音声ファイル（WAV等）の中身は、時間軸に沿った**振幅値の列**。マイクが空気の振動を拾って、1秒あたり数千〜数万回の値として記録したもの。Scribaでは16,000回/秒（16kHz）で記録している。

```
時間 →  [0.01, -0.03, 0.05, 0.02, -0.01, ...]   ← これが音声データ
```

## モノラル（1ch）

**1本の数値列**。すべての音が1つの信号に混ざっている。

```
ch1: ■■■■■■■■■■■■■■■■■■■■■■■■■■■■   ← 全部ここに入る
```

人の声もBGMもノイズも、全部足し算されて1本の波形になる。一度混ざると元の個別の音には戻せない（不可逆）。

今回の `-ac 1` がこれ。BlackHoleの音（相手の声）と外部マイクの音（自分の声）を**足し算して1本にしていた**。

## ステレオ（2ch）

**2本の数値列が並列に記録される**。左（L）と右（R）。

```
L: ■■■■■■■■■■■■■■■■■■■■■■■■■■■■   ← 左チャンネル
R: ■■■■■■■■■■■■■■■■■■■■■■■■■■■■   ← 右チャンネル
```

通常の音楽ファイルでは、LとRに微妙に違う音を入れることで「左から聞こえる」「右から聞こえる」という空間表現をしている。

## なぜステレオで話者分離できるのか

ポイント: **LとRに入れる音は自由に選べる**。

Scribaの場合、2つの**物理的に別の入力デバイス**がある:

| デバイス | 拾う音 | 割り当て |
|---|---|---|
| BlackHole 2ch | Teamsから出る音（相手の声） | → L チャンネル |
| 外部マイク | 自分の周囲の音（自分の声） | → R チャンネル |

```
L: [相手] 「資料を共有します」
R: [自分] 「お願いします」
```

これは「ステレオ録音で左右の空間を表現する」という本来の使い方ではなく、**2つの独立した録音を1つのファイルに同期して格納する**というトリック。

録音後に分離するのは単純:

```bash
# L（相手の声）だけ取り出す
ffmpeg -i recording.wav -af "pan=mono|c0=FL" other.wav

# R（自分の声）だけ取り出す
ffmpeg -i recording.wav -af "pan=mono|c0=FR" self.wav
```

`pan=mono|c0=FL` は「モノラルに変換するが、素材はFront Left（左チャンネル）だけ使え」という意味。

## モノラルミックスとの比較

| 方式 | コマンドの違い | 結果 |
|---|---|---|
| モノラル混合 (`-ac 1`) | 2入力を足し算して1chに | 混ざる。分離不可能 |
| ステレオ分離 (`-ac 2`) | 2入力をL/Rに別々に格納 | あとから個別に取り出せる |

`-ac 1` と `-ac 2` の1文字の違いだが、情報量が全く違う。

## なぜAI話者分離（pyannote等）より確実か

AI話者分離（pyannote等）は**混ざった1本の音声から「誰が喋っているか」を推定する**。声の特徴量（音の高さ、話し方のクセ）を分析して区別するが:

- 声質が似ていると間違える
- 同時に喋ると分離できない
- モノラル音声が前提なので、情報が少ない

一方、ステレオ2ch方式は:

- 物理的に別のデバイスから来ているので**推定ではなく事実**
- 同時に喋っても問題なし（別チャンネルだから）
- AIモデル不要。ffmpegだけで完結
- 精度100%（デバイスの割り当てが正しい限り）

## 制約・注意点

### 自分の声がBlackHole側に漏れる可能性

Teamsは自分のマイク音声を相手に送るが、**エコーキャンセル後の音声がTeamsの出力に混入する場合がある**（スピーカーフォン使用時など）。ヘッドフォン使用時はほぼ問題ない。

### マイク側に相手の声が漏れる可能性

スピーカーで再生している場合、相手の声がマイクに入る（ハウリング的な漏れ）。ヘッドフォン使用なら問題なし。

### つまり

ヘッドフォン使用時は**ほぼ完全に分離できる**。スピーカー使用時は若干の漏れがある。

## Scribaでの活用

```
録音時
  BlackHole → L ch（相手）
  外部マイク → R ch（自分）
     ↓ 1つのWAVファイルに同期記録

文字起こし時
  L ch → Whisper → 相手の発言テキスト
  R ch → Whisper → 自分の発言テキスト
     ↓ タイムスタンプで統合

表示時
  [相手] 資料を共有します
  [自分] お願いします
  [相手] 次の議題に移ります
```

pyannoteなしで、ffmpegだけで話者分離が実現できる。
